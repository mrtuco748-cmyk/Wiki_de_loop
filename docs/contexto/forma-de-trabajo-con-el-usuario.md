- Batch rápido, no incremental paso a paso.

## Checklist antes de cada acción
- [ ] Leer docs/contexto relevantes (especialmente arquitectura/convenciones)
- [ ] Comunicar qué/impacto/alternativas
- [ ] Esperar confirmación
- [ ] Documentar en historial.md

## Reglas No Negociables
- No romper estética dark-fantasy sin aprobación
- No agregar deps/build tools sin D-X
- No exponer secretos (n/a)
- Respuestas concisas, sin rodeos
